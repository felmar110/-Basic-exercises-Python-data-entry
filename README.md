#Ejercicios Básicos de Python y Análisis de Datos
Este repositorio contiene una colección de ejercicios en Python enfocados en la manipulación de datos y el análisis básico. El objetivo es practicar funciones clave de Python y aplicar estas habilidades a un conjunto de datos simple para extraer información relevante.

#Contenido del Cuaderno
El cuaderno está dividido en las siguientes secciones:

#Parte A — Funciones de Manipulación de Datos
En esta sección, se desarrollan e implementan diversas funciones para manipular diferentes estructuras de datos en Python:

filtrar_pares(numeros: list) -> list: Filtra una lista de números y devuelve solo los que son pares.
contar_vocales(texto: str) -> dict: Cuenta la ocurrencia de cada vocal (a, e, i, o, u) en un texto dado, ignorando mayúsculas y minúsculas.
invertir_diccionario(d: dict) -> dict: Invierte un diccionario, donde los valores se convierten en claves y las claves originales en valores. Si hay valores duplicados, se retiene la última clave asociada con ese valor.
aplanar(lista: list) -> list: Aplana una lista anidada (una lista que contiene otras listas) en una única lista plana, utilizando recursividad.

#Parte B — Análisis de Datos de Estudiantes
Esta sección se centra en el análisis de un conjunto de datos de estudiantes, donde cada estudiante tiene un nombre, una nota, una asignatura y las horas de estudio. Se realizan los siguientes análisis:

B.1 — Calcula la nota media: Calcula la nota media de todos los estudiantes.
B.2 — Encuentra al mejor estudiante: Identifica al estudiante con la nota más alta.
B.3 — Media por asignatura: Calcula la nota media para cada asignatura.
B.4 — Cuenta estudiantes con >=20h de estudio y nota >=7: Cuenta cuántos estudiantes cumplen con el criterio de haber estudiado 20 horas o más Y haber obtenido una nota igual o superior a 7.
